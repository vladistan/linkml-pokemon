# Original Pokemon Knowledge Graph Data

This directory contains a copy of the original Pokemon Knowledge Graph dataset from [pokemonkg.org](https://pokemonkg.org/).

## Files

| File | Description |
| --- | --- |
| `poke-a.nq` | Full knowledge graph dump in N-Quads format |
| `pokemon-ontology.ttl` | Original Pokemon ontology in Turtle format |

## Source

The original data is maintained by the Pokemon Knowledge Graph project:
<https://pokemonkg.org/>
